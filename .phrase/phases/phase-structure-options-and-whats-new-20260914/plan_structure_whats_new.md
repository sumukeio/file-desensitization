# Phase Plan: 结构可选脱敏 + 用户可见更新记录

> **阶段标识**：`phase-structure-options-and-whats-new-20260914`  
> **状态**：方案已锁定

---

## 里程碑

| 顺序 | 里程碑 | 对应任务 | 说明 |
| :--- | :--- | :--- | :--- |
| M1 | 引擎与 API 支持可选结构脱敏 | `task001` | 先数据后结构；Form 布尔透传 |
| M2 | 前端勾选与联调 | `task002` | 上传区选项 + 端到端可验证 |
| M3 | 「最近更新」A+B | `task003` | 顶栏入口、红点、自动弹一次、用户向文案 |
| M4 | 文档与变更闭环 | `task004` | 方案文档、CHANGELOG、阶段 change 回写 |

## 架构边界

- **后端**：仅扩展上传 Form 与 `custom_options`；不改 Profile 枚举语义。
- **引擎**：结构脱敏发生在数据行处理完成之后；Sheet 名必须满足 Excel 合法性与唯一性。
- **前端**：用户向更新与开发向 CHANGELOG 分离；未读状态仅存浏览器 `localStorage`。
- **兼容**：旧客户端不传新字段时，服务端按 `false` 处理。

## 风险与预案

| 风险 | 预案 |
| :--- | :--- |
| 先改列名导致实体匹配失效 | 硬性顺序：先数据后结构；测试覆盖 |
| Sheet 重名 / 非法字符 | 截断 + 唯一后缀；测试覆盖 |
| 用户误开列名脱敏影响喂 AI | UI 提示文案；默认关闭 |
| 自动弹窗打扰 | 每版本仅自动一次；可手动再开 |

## 推荐实施顺序

严格按 `task001 → task002 → task003 → task004` 单任务推进；**禁止**在一个回合内连续做完多个 task 而不等待人类确认。
