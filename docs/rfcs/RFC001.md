# RFC001 — 可选：列名 / Sheet 名脱敏

> **状态**：`[已实施]`  
> **提出日期**：2026-09-14  
> **锁定日期**：2026-09-14  
> **关联阶段**：`.phrase/phases/phase-structure-options-and-whats-new-20260914/`

---

## 1. 需求原意（白话）

脱敏前，让用户自己决定：

1. **要不要**对「列名」（表头第一行）做脱敏；
2. **要不要**对「工作表名称」（Sheet 名）做脱敏。

**不勾选 = 不处理**，行为与现在完全一致（只处理表格里的单元格内容）。

---

## 2. 可行性结论

**可行，成本低，默认关闭，无破坏性变更。**

与现有 FastAPI + `ExcelProcessor` + 前端 Form 上传链路契合；引擎已预留 `custom_options`，队列层当前传 `None`，可直接接入。

---

## 3. 已锁定设计决策

### 3.1 默认与交互

| 项 | 决策 |
| :--- | :--- |
| 默认 | 两个开关均 **关闭（不勾选）** |
| 位置 | 上传区附近，脱敏前可见、可勾选 |
| 提示文案 | 需提示：勾选列名脱敏后，AI 更难理解表结构，仅在列名本身含敏感信息时使用 |

### 3.2 处理顺序（硬性）

1. **先用原始列名**完成全部数据行脱敏（保证 `PSEUDO_COLUMN_MAPPING` 等列名匹配仍正确）；
2. **再**按开关决定是否改写第 1 行列名、是否重命名 Sheet。

禁止先改列名再跑数据行逻辑。

> **实施说明**：表头行定位已由 [`RFC003`](file:///e:/AIProject/File%20Desensitization/docs/rfcs/RFC003.md) 承接（自动识别 / 手动指定）。列名脱敏应作用在**识别出的表头行**上。

### 3.3 脱敏策略（与当前三档 Profile 对齐）

| 开关开启时 | `ai_friendly` | `standard_mask` | `strict_anon` |
| :--- | :--- | :--- | :--- |
| 列名 | 假名化，如 `列_01`（同名跨 Sheet 尽量一致） | 中间打星 | `ANON_xxxx` |
| Sheet 名 | 假名化，如 `Sheet_01` | 中间打星或假名（以实现时保证唯一为准） | `ANON_xxxx` |

**Sheet 名约束**：最长 31 字符；禁止 `\ / ? * [ ]`；同一工作簿内必须唯一。引擎内需做截断与唯一化（如加后缀）。

### 3.4 Diff 预览

- 数据单元格样本：仍用 **原始** Sheet 名 / 列名 定位，避免预览对不上。
- 若发生了结构脱敏：额外追加少量 `mask_type` 为 `HEADER` / `SHEET` 的样本。

### 3.5 API 约定（实施时）

上传接口在现有 `profile` 之外增加两个 Form 布尔字段（名称可微调，语义不变）：

- `mask_headers`：默认 `false`
- `mask_sheet_names`：默认 `false`

经 `TaskQueueManager` 传入 `ExcelProcessor.process(..., custom_options=...)`。

---

## 4. 明确不做（本次范围外）

- 不脱敏文件名
- 不处理多级表头 / 合并单元格表头的复杂语义
- 不引入新的第三方依赖
- 不改变三档 Profile 的既有数据行行为（仅新增可选结构处理）

## 6. 验收标准（摘要）

1. 两开关默认关闭时，输出与改造前一致（列名、Sheet 名不变）。
2. 仅勾选列名：识别出的表头行被脱敏，Sheet 名不变；数据行实体假名仍按**原始列名**匹配。
3. 仅勾选 Sheet 名：Sheet 被合法重命名且不重名；列名不变。
4. 两开关都勾选：两者均处理，且顺序符合 §3.2。
5. 相关自动化测试通过。

## 7. 后续补充说明

本 RFC 已完成“**是否对列名 / Sheet 名脱敏**”这一层能力。

但实际业务里，**表头不一定在第 1 行**；同一文件内**不同 Sheet 的表头行也可能不同**。

这些问题不在本 RFC 范围，已由 [`docs/rfcs/RFC003.md`](file:///e:/AIProject/File%20Desensitization/docs/rfcs/RFC003.md) 承接，产品路线为：

- **A**：说清楚（默认自动、按 Sheet 单独判断）
- **B**：处理完展示各 Sheet 识别结果
- **C**：按 Sheet 单独改行号（暂缓）

「效果对比如何展示列名 / Sheet 名脱敏结果」不在本 RFC 范围，已由 [`docs/rfcs/RFC004.md`](file:///e:/AIProject/File%20Desensitization/docs/rfcs/RFC004.md) 承接：按工作表 Tab 切换查看，结构脱敏（列名、Sheet 名）与数据样本分区展示。
