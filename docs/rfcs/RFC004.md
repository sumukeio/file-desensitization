# RFC004 — 效果对比：分 Sheet 切换 + 结构脱敏可见

> **状态**：`[已实施]`（含 issue002 采样与弹窗信息架构修订）  
> **提出日期**：2026-09-14  
> **锁定日期**：2026-09-14  
> **关联**：[`RFC001`](file:///e:/AIProject/File%20Desensitization/docs/rfcs/RFC001.md) 列名/Sheet 名脱敏的可视化反馈

---

## 1. 问题

「效果对比」原先为全文件扁平列表 + 全局最多 30 条样本：

- 先处理的 Sheet 容易占满配额，后续 Sheet 可能**没有样本**
- 用户无法**按 Sheet 切换**聚焦查看
- 勾选「列名 / 工作表名称脱敏」后，HEADER / SHEET 样本可能被数据样本**挤掉**

---

## 2. 已锁定方案

### 2.1 后端采样（issue002 修订）

- **每个 Sheet 独立配额**：
  - 结构样本（`HEADER` / `SHEET`）每 Sheet 最多 **5** 条
  - 数据单元格样本每 Sheet 最多 **5** 条
- 两类配额互不占用；先处理的 Sheet **不得**挤掉后续 Sheet
- 软全局上限：2000（防极端膨胀；日常由每 Sheet 限额约束）
- 返回 `sheet_renames`：`{ 原始Sheet名: 脱敏后Sheet名 }`（未改名则不出现）

### 2.2 前端展示（issue002 修订）

- 弹窗顶部：若有改名，**仅一句摘要**「已将 N 个工作表重命名」（不再列全表）
- **Tab 切换**：横向滚动；当前 Tab 高亮；Tab 上显示「原名 → 新名」
- 当前 Tab 内分区展示：
  1. 表头识别行号 + 纠错（RFC005）
  2. **列名 / 结构变更**（≤5）
  3. **数据脱敏**（≤5）
- 去掉 Tab 内重复的「工作表」列

---

## 3. 明确不做

- 不做整表 Diff / 全量单元格预览
- 不做上传前按 Sheet 编辑
- 不做顶部全量 Sheet 改名对照表

---

## 4. 验收标准

1. 多 Sheet 文件每个 Sheet 在效果对比中均可见（有 Tab；有变更则有对应分区样本，且不被前面 Sheet 挤掉）。
2. 勾选列名脱敏时，对应 Sheet 的 HEADER 样本稳定可见（每 Sheet ≤5）。
3. 勾选 Sheet 名脱敏时，顶部一句摘要可见改名数量；当前 Tab 可见原名 → 新名。
4. 自动化测试覆盖多 Sheet 配额与「后续 Sheet 仍有样本」。
