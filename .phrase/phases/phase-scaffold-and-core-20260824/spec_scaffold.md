# Phase Spec: 项目脚手架搭建与核心脱敏引擎基础 (phase-scaffold-and-core-20260824)

> **阶段状态**：`[执行中]`  
> **创建日期**：2026-08-24

---

## 1. 阶段目标 (Goals)
1. 建立 `.phrase/` 阶段治理体系与规范配置；
2. 构建后端 Python FastAPI + openpyxl 脱敏引擎架构骨架与 5 层脱敏规则模型；
3. 构建前端极简 SaaS 控制台脚手架（拖拽上传、排队看板、Diff 对比预览、下载）；
4. 建立基于 `docs/Example/` 真实数据（亚马逊利润表、FBA库存表、组织架构表）的自动化测试套件与联调验证。

## 2. 非本阶段目标 (Non-Goals)
- Word (.docx) / PDF (.pdf) 等非表格文件格式的处理（留待 Phase 3 扩展）；
- 复杂的分布式多节点 Celery 集群部署（本阶段使用单机轻量异步队列）。

## 3. 验收标准 (Acceptance Criteria)
- [ ] `.phrase/` 体系与文档全量初始化完成；
- [ ] 后端目录与核心脱敏规则接口就绪；
- [ ] 前端界面可在浏览器正常加载，交互组件结构完备；
- [ ] 自动化测试用例（pytest）全部通过，验证脱敏效果且无语法/逻辑退化。
